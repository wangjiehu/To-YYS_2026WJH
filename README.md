## 🎮 我们要一起通关的内容 (100 个趣味小挑战)

这 100 个关卡不是冷冰冰的题库，而是一条慢慢铺开的 Python 成长路线：从第一行代码开始，一路练到能做出自己的小项目。每一步都像拆开一层礼物，不着急、不跳步，一起把“会写代码”变成“能用代码解决问题”，慢慢走向独立开发。

### 🌱 Level 1-30：基础语法
从 `print`、变量、算术运算、字符串开始，逐步练习条件判断、循环、列表、元组、字典、集合和函数。这里是整座游乐场的地基，把这些小魔法练熟，后面的挑战才会跑得更稳。

### 🛠️ Level 31-40：工程化与调试
开始学习更像真实开发者的工作方式：拆分文件、组织模块、阅读报错、定位问题、写出更清楚的代码。遇到 bug 也不用慌，我们把它当成线索，一点点追到真相。

### 📁 Level 41-50：数据文件处理
一起处理 TXT、CSV、JSON 等常见数据文件，学习读写、清洗、统计和转换。代码不只是在屏幕上跑一跑，它也能帮你整理真实世界里有点乱的数据。

### 🧰 Level 51-60：命令行工具
把 Python 写成可以在命令行里使用的小工具：接收参数、输出结果、批量处理任务。到这里，你会开始感觉代码像一件随身小装备，能帮自己省下不少重复劳动。

### 🌐 Level 61-70：Web/API
探索网络请求、API 调用、数据解析和简单 Web 服务。我们会让程序学会和外面的世界打招呼，读取远方的数据，也把自己的结果更友好地展示出来。

### 🗄️ Level 71-80：SQLite 数据库
进入数据库小世界，学习建表、增删改查、条件筛选和基础关联。数据不再只是临时变量，而是可以被保存、查询和管理的小宝库。

### 🧪 Level 81-90：软件设计与测试
练习面向对象、职责拆分、异常处理、单元测试和更清晰的项目结构。这里的目标不是把代码写得花哨，而是让它更好读、更好改，也更经得起下一次升级。

### 👑 Level 91-100：综合项目
最后 10 关会把前面学过的内容串起来，完成更完整的小项目：既有数据处理，也有命令行、API、数据库、测试和界面展示的综合练习。通关之后，你不会被一句“从零开始做个项目”吓住，而是能一步步拆问题、搭结构、写逻辑，真正向独立开发靠近。
