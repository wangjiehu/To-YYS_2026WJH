## 🎨 关于这个学习平台

这不仅仅是一个题库，而是一份特别准备的生日惊喜。平台在底层集成了 **浏览器端 Python 编译引擎 (Pyodide)**，无需安装任何软件或配置复杂的 Python 环境，打开网页就可以直接编写、运行、验证 Python 代码。

为了让你在学习编程时感到轻松和舒适，整个系统融入了许多细节：
* 🍵 **米白护眼主题 (Cream Theme)**：和谐柔和的配色系统，长时间敲代码也不会感到疲劳。
* 🌙 **深色护眼模式**：支持一键切换到深色模式，适应夜间学习场景。
* 🔊 **动态声效反馈**：过关时有欢快的和弦，出错时有低沉的提示音，支持全局静音。
* 🎉 **Canvas 粒子烟花**：每通关一个关卡，屏幕上都会燃放绚丽的庆祝彩屑。
* 💡 **无缝侧边答案抽屉**：学习 `java-path` 的优秀工程设计，点击查看答案时，答案面板会作为固定抽屉完全覆盖左侧两列（地图和讲解），露出右侧的编辑器，让你一边对照参考答案，一边流畅编程。
* ⚡ **多重 CDN 自动切换**：内置多组国内外加速镜像节点，即使本地加载受到浏览器安全策略（如 CORS）限制，系统也会在几秒内自动感知并无缝切换至在线 CDN。

## 🎮 我们的修炼路线 (100 个趣味关卡)

关卡难度呈温和的螺旋形上升，从第一行 `print` 开始，一直到能够编写具有数据库、命令行和 API 的独立小项目：

| 阶段 | 关卡范围 | 核心内容 | 学习目标 |
| :--- | :--- | :--- | :--- |
| 🌱 **Level 1** | 1 - 15 | 基础语法与容器 | 熟悉变量、基本数学运算、条件分支、循环，以及列表、字典等基本容器。 |
| 🛠️ **Level 2** | 16 - 30 | 函数与核心数据结构 | 学习封装函数、变量作用域、列表推导式、集合和元组等，初步建立模块化思维。 |
| 📁 **Level 3** | 31 - 50 | 工程组织与文件处理 | 开始拆分模块、进行断言调试、读写 CSV/JSONL 数据，掌握真实开发中的文件整理。 |
| 🧰 **Level 4** | 51 - 65 | 命令行工具与网络 API | 学习解析命令行参数、构造 API 请求、处理网络响应，让程序学会和外部世界打招呼。 |
| 🗄️ **Level 5** | 66 - 80 | SQLite 数据库入门 | 引入关系型数据库，学习基本的 SQL 增删改查，完成数据持久化存储。 |

## 💻 本地运行与开发指南

如果你希望在本地离线运行此平台，可以直接通过以下两种方式打开：

### 方式 A：直接双击打开（推荐）
直接在资源管理器中双击 [index.html](index.html) 文件即可。
> 💡 *提示：本平台已实现智能降级与跨域自动感知，如果直接双击打开导致本地 Pyodide 核心文件受到浏览器 CORS 安全限制，它会自动智能切换至在线 CDN 加速线路运行，确保编译器完美载入。*

### 方式 B：启动本地 Web 服务
如果你想在本地进行调试或开发，可以在当前目录下启动一个 Python 简易服务器，这能完美避开任何浏览器的跨域拦截：
```powershell
# 1. 运行本地下载脚本（如果本地 pyodide 目录尚不完整）
python download_pyodide.py

# 2. 启动本地 Web 服务器
python -m http.server 8000
```
启动后在浏览器中访问：👉 **`http://localhost:8000/`** 👈
